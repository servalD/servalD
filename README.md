Blockchain / backend engineer based in Paris, France. I work across the stack, from Solidity contracts and Avalanche L1 infrastructure down to Rust systems programming, with a focus on getting things production-ready: tested, audited, deployed, and monitored.

**Currently:** building Avalanche L1 tooling at e36knots, contributing to the Suzaku ecosystem.

## What I work on

- **Avalanche L1 tooling**: CLI tooling, staking/validator infra, deployment scripts for custom Avalanche L1s.
- **Smart contracts**: Solidity (Foundry), contract security/audit practice, cross-chain design.
- **Full-stack applications**: NestJS + Next.js/React, hexagonal architecture, PostgreSQL/TypeORM.
- **Infra & delivery**: Docker, Terraform, Ansible, CI/CD.
- **Systems programming**: Rust, Go.

Smart contract exploitation and audit practice.

- **[ethernaut](https://github.com/servalD/ethernaut)**: Foundry-based solutions to OpenZeppelin's Ethernaut smart contract security CTF.
- **[Audit-ESGI](https://github.com/servalD/Audit-ESGI)**: Vulnerability exploitation exercises (reentrancy, weak randomness) against deployed contracts, with Foundry scripts.
